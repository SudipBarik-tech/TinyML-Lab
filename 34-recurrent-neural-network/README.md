# Experiment 34 — Recurrent Neural Network

## Objective

Train a compact SimpleRNN sequence classifier and export it as a fully quantised INT8 TensorFlow Lite model for microcontroller inference.

## Dataset

The experiment creates short two-channel sequences. The class depends on the temporal relationship between the channels rather than on a single isolated sample, making the task suitable for recurrent processing.

## Workflow

1. Generate reproducible synthetic sequences.
2. Train a small `SimpleRNN` classifier.
3. Evaluate sequence-level classification accuracy.
4. Convert the fitted model to full-integer INT8 TensorFlow Lite.
5. Export the model bytes and quantisation parameters to a C header.
6. Run the sequence model with TensorFlow Lite for Microcontrollers.

## Files

- `train.py` — dataset generation, RNN training, evaluation and INT8 export.
- `embedded/rnn_demo.ino` — Arduino/ESP32 inference example.
- `embedded/rnn_model.h` — generated by `train.py`.

## Run

```bash
python 34-recurrent-neural-network/train.py
```

## Embedded note

The model is deliberately small. Actual tensor-arena requirements and inference latency depend on the target board and TensorFlow Lite Micro build, so they should be measured on hardware rather than estimated from desktop execution.
