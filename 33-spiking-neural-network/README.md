# Experiment 33 — Spiking Neural Network

## Objective

Create a small integrate-and-fire spiking classifier that can run without a neural-network runtime on a microcontroller.

## Idea

Two input channels are converted into short binary spike trains. A small bank of integrate-and-fire neurons accumulates weighted input spikes. Whenever a membrane value crosses its threshold, the neuron emits a spike and the threshold value is subtracted from the membrane.

The hidden spike counts are then classified by a lightweight linear readout.

## Workflow

1. Generate two-class rate-coded spike sequences.
2. Simulate a four-neuron integrate-and-fire hidden layer.
3. Count hidden spikes over the time window.
4. Train a logistic readout on those spike counts.
5. Export synaptic weights, thresholds and readout parameters to C/C++.
6. Reproduce the same event-driven update loop on Arduino/ESP32.

## Files

- `train.py` — spike generation, integrate-and-fire simulation, readout training and export.
- `embedded/snn_demo.ino` — device-side spike simulation and classification.
- `embedded/snn_model.h` — generated by `train.py`.

## Run

```bash
python 33-spiking-neural-network/train.py
```

## TinyML note

The example is intentionally small and uses explicit event-driven state updates instead of a specialised SNN framework. This keeps the inference path understandable and portable to constrained hardware.
