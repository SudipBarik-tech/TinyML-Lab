# Experiment 35 — Liquid-Inspired Recurrent Network

## Objective

Explore a compact recurrent model with leaky state dynamics and trainable output weights, designed to illustrate the adaptive temporal behaviour associated with liquid-style neural models.

## Scope

This experiment is intentionally labelled **liquid-inspired**. It is not a full implementation of a specialised Liquid Time-Constant (LTC) package. Instead, it uses a small recurrent state update with neuron-specific leakage factors:

```text
h(t) = (1 - alpha) * h(t-1) + alpha * tanh(Wx*x(t) + Wh*h(t-1) + b)
```

Different `alpha` values produce different effective time constants. A lightweight logistic readout is trained from the final recurrent state.

## Workflow

1. Generate short temporal classification sequences.
2. Initialise a small stable recurrent reservoir.
3. Apply neuron-specific leakage factors.
4. Extract the final recurrent state for every sequence.
5. Train a logistic readout.
6. Export recurrent weights, leakage factors and readout coefficients.
7. Reproduce the recurrent update directly in C++ on the microcontroller.

## Files

- `train.py` — temporal dataset generation, liquid-inspired state simulation, readout training and export.
- `embedded/liquid_demo.ino` — manual recurrent inference on Arduino/ESP32.
- `embedded/liquid_model.h` — generated by `train.py`.

## Run

```bash
python 35-liquid-neural-network/train.py
```

## Embedded note

Because the recurrent update is written explicitly, this experiment does not require TensorFlow Lite Micro. The main deployment costs are the recurrent weight matrix, hidden state and repeated matrix-vector operations.
