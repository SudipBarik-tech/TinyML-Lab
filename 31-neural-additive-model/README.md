# Experiment 31 — Neural Additive Model

## Objective

Build a compact Neural Additive Model (NAM) for binary classification and export it as an INT8 TensorFlow Lite model for embedded inference.

## Idea

A NAM models the prediction as a sum of separate feature-wise neural functions:

```text
logit(x) = f1(x1) + f2(x2) + ... + fk(xk)
```

This makes the model easier to inspect than a fully connected black-box network because each input feature has its own small subnetwork before the contributions are added.

## Workflow

1. Generate a reproducible four-feature binary dataset.
2. Standardise the input features.
3. Train one small neural subnetwork per feature.
4. Add the feature contributions and apply a sigmoid output.
5. Convert the fitted network to full-integer INT8 TensorFlow Lite.
6. Export the model bytes and preprocessing constants to a C header.
7. Run the model with TensorFlow Lite for Microcontrollers.

## Files

- `train.py` — dataset generation, training, evaluation and INT8 export.
- `embedded/nam_demo.ino` — Arduino/ESP32 inference example.
- `embedded/nam_model.h` — generated by `train.py`.

## Run

```bash
python 31-neural-additive-model/train.py
```

## Embedded note

The training script also exports the feature means and scales, so device-side preprocessing matches the desktop workflow. RAM, flash and latency figures should be measured on the actual target board before being reported.
