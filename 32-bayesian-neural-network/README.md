# Experiment 32 — Bayesian Neural Network (MC Dropout Approximation)

## Objective

Study predictive uncertainty with a compact neural network using Monte Carlo dropout, then export the deterministic inference path as an INT8 TensorFlow Lite model for embedded deployment.

## Why MC dropout?

A full variational Bayesian neural network introduces additional probability distributions and sampling logic that are difficult to justify on a small microcontroller. This experiment therefore uses **MC dropout as a practical Bayesian approximation** during desktop evaluation.

Repeated stochastic forward passes provide a mean prediction and a simple uncertainty estimate. On the embedded target, dropout is disabled and the compact deterministic inference graph is deployed.

## Workflow

1. Generate a reproducible binary dataset.
2. Standardise the inputs.
3. Train a small dense network with dropout layers.
4. Run repeated stochastic forward passes with `training=True`.
5. Measure mean probability and prediction spread.
6. Convert the inference graph to full-integer INT8 TensorFlow Lite.
7. Export model bytes and preprocessing constants for TensorFlow Lite Micro.

## Files

- `train.py` — training, MC-dropout uncertainty study and INT8 export.
- `embedded/bnn_demo.ino` — deterministic embedded inference example.
- `embedded/bnn_model.h` — generated by `train.py`.

## Run

```bash
python 32-bayesian-neural-network/train.py
```

## Limitation

This is not presented as an exact variational Bayesian neural network. The uncertainty component is an MC-dropout approximation, while the microcontroller deployment uses the deterministic inference graph.
